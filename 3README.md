# Task 3: Student Management System in C

A menu-driven program to add, display, and search student records.

## Features
- Add a student's roll number, name, and marks
- Display all records with a calculated grade
- Search for a student by roll number
- Validates marks from 0 to 100
- Stores up to 100 records while the program is running

## Concepts used
Structures, arrays, functions, loops, conditional statements, and input/output.

## Compile and run
```bash
gcc main.c -o student_management
./student_management
```

## Grade scale
- A: 90–100
- B: 75–89.99
- C: 60–74.99
- D: 40–59.99
- F: below 40

## Limitation
Records are kept in memory and are cleared when the program exits. Names are entered as one word in this beginner version.
