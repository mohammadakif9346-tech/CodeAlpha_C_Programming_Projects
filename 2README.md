# Task 2: Number Guessing Game in C

A command-line game where the player guesses a randomly generated number from 1 to 100.

## Features
- Generates a random number
- Gives higher/lower hints
- Counts the number of attempts
- Checks that the guess is within the stated range

## Concepts used
Variables, loops, `if/else`, functions from the standard library, random numbers, and input/output.

## Compile and run
```bash
gcc main.c -o guessing_game
./guessing_game
```

## Example
```text
I have selected a number between 1 and 100.
Your guess: 40
Too low. Try a higher number.
```
