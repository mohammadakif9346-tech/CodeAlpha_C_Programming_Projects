# Task 1: Simple C Calculator

A beginner-friendly command-line calculator written in C.

## Features
- Addition, subtraction, multiplication and division
- Uses functions and a `switch` statement
- Checks division by zero
- Allows repeated calculations

## Concepts used
Variables, input/output, functions, conditional logic, `switch`, and loops.

## Compile and run
```bash
gcc main.c -o calculator
./calculator
```

## Example
```text
Enter an expression (example: 12 + 5): 12 + 5
Result: 17.00
```
